# Hezarfen: Galata'dan Üsküdar'a 🦅

1632 yılında Galata Kulesi'nden Üsküdar Doğancılar Meydanı'na uçan Hezarfen Ahmed Çelebi'nin tarihi uçuşunu konu alan tarayıcı tabanlı 3D uçuş simülasyonu.

## Özellikler
- **Kamera / Vücut Takibi (MediaPipe Pose):** Web kamerası karşısında kollarınızı iki yana açarak Hezarfen'in kanatlarını doğrudan yönetin.
- **Klavye Modu:** Rahat süzülüş için klavye (`W/A/S/D` ve `Space`) kontrolleri.
- **3D İstanbul & Tarihi Yapılar:** Galata Kulesi, Kız Kulesi, Topkapı Sarayı, Dolmabahçe Sarayı, Vodafone Park ve Boğaz vapurları.
- **Three.js & WebGL:** Gerçekçi Boğaz suları, atmosfer ve 3D modeller.

## Çalıştırma
Projeyi yerel bir web sunucusunda çalıştırmak için:

```bash
python -m http.server 8000
```

Ardından tarayıcınızdan `http://localhost:8000` adresine gidin.
